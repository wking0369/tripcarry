# 크리에이터 허브

영어권 크리에이터의 한국 인스타그램 계정을 운영하기 위한 공개 소개 페이지와 비공개 작업 도구예요.
(저장소 이름은 예전 프로젝트 이름인 tripcarry 그대로예요.)

## 화면

| 주소 | 내용 |
|---|---|
| `/` | 공개 소개 페이지와 파일럿 신청 폼 (영어) |
| `/studio` | 분석: 팔로워 변화, 터진 게시물, 스타일별 성과 |
| `/studio/data` | 수치 입력: 직접 입력, CSV |
| `/studio/archive` | 보관함: 달별 게시물, 조회수 순서 |
| `/studio/trial` | 트라이얼: 상위 릴스 변형본, 승인, 하루 최대 2개 예약 |
| `/studio/subtitles` | 자막 편집: 폰트·크기·위치 조정, 영상에 입혀 받기 |
| `/studio/people` | 인물 정보(경력·명언)와 카드뉴스 PNG |
| `/studio/reports` | 2주 보고서 |
| `/studio/leads` | 파일럿 신청 목록 |

## 동작 원칙

- **데이터:** 인스타에 연결되어 있지 않아요. 분석과 보고서는 툴에 입력한 값으로 계산해요. 처음 열면 가상 샘플이 들어가고, 화면 위쪽 버튼으로 지울 수 있어요.
- **트라이얼:** 승인한 변형본만 예약돼요. 지금은 **테스트 모드**라 시간이 되면 기록만 남고 실제로 올라가지 않아요. 실제 게시는 `lib/hub/scheduler.ts`의 `postDueItems`에 인스타 API 호출을 붙이면 돼요.
- **자막:** 브라우저에서 자막을 PNG로 그려 보내고 서버의 ffmpeg가 영상에 얹어요. 그래서 미리보기와 결과물이 같아요.
- **카드뉴스:** 입력한 문장을 그대로 그려요. AI를 거치지 않아요.
- **보고서:** 숫자는 코드로 계산하고, AI는 그 숫자를 해석하는 글만 써요. 기간이 끝나면 서버가 5분 간격으로 확인해서 자동으로 만들어요. AI 키가 없으면 규칙으로 만든 초안이 나와요.

## 실행

```bash
npm install
ADMIN_PASSWORD=test DATA_DIR=./data AI_MOCK=1 npm run dev   # http://localhost:3000
```

ffmpeg가 설치되어 있어야 자막 입힌 영상을 만들 수 있어요.

## Railway 배포

저장소의 `Dockerfile`로 빌드해요. ffmpeg가 함께 설치돼요.

| 변수 | 설명 |
|---|---|
| `ADMIN_PASSWORD` | 스튜디오 비밀번호 (필수) |
| `DATA_DIR` | `/data` (Volume 경로) |
| `OPENAI_API_KEY` | AI 자막 초안, 첫 문장 제안, 보고서 글 |
| `OPENAI_TEXT_MODEL` | 사용할 모델 (선택) |

- Volume을 `/data`에 붙여야 재배포해도 데이터와 영상이 남아요. 영상이 쌓이므로 Volume 용량을 확인해 주세요.
- 예전 사전등록 명단은 같은 Volume에 그대로 있고, 로그인한 뒤 `/api/admin/export`에서 CSV로 받을 수 있어요.
