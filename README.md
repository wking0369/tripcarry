# TripCarry — 여행자 직구 매칭 (P2P 크라우드 쇼핑) 데모

구매자는 해외 직구 배송비·관세 부담을 줄이고, 여행자는 캐리어 빈 공간으로 여행비를 버는 P2P 플랫폼 아이디어를 검증하는 데모예요.
로그인 없이 누구나 볼 수 있고, 데이터는 방문자 브라우저(localStorage)에만 저장돼요.

## 화면

| 주소 | 내용 |
|---|---|
| `/` | 랜딩: 도쿄 → 서울 매장 한정품 · 리셀가 비교 · 이용 방법 · 공급자 모집 |
| `/drops` | 도쿄 한정품 예시 카드와 "이거 원해요" 버튼 (품목별 관심 집계) |
| `/requests` | 구매 요청 등록 — 등록할 때 면세 가드가 금지 품목·한도 검사 |
| `/trips` | 여행 일정 등록 → 경로·날짜가 맞는 요청 추천 → 수락 |
| `/orders` | 에스크로 흐름: 결제 → 보관 → 구매(영수증) → 전달(사진) → 수령 확인 → 정산 |
| `/customs` | 7개국 면세 한도와 품목별 반입 규칙 |

## 면세 자동 가드

- 반입 금지 품목(육가공품·생과일·모조품·무기·마약류)은 종류 선택이나 물품 이름만으로 등록을 막아요.
- 면세 한도는 **여행자 한 명의 이번 여행 전체**로 합산해요. 초과하면 예상 세금을 미리 결제하는 조건으로만 수락할 수 있어요.
- 규정표와 판정 로직: `lib/customs.ts` · 수수료: `lib/fees.ts` · 데이터 저장: `lib/store.ts`
- 면세 한도·세율·환율은 참고용 고정값이에요. 대리 구매 물품은 나라에 따라 개인 휴대품으로 인정되지 않을 수 있어서, 정식 서비스 전에는 관세사·변호사 검토가 필요해요.

## 실행

```bash
npm install
npm run dev      # http://localhost:3000
npm run build && npm start
```

## 마케팅 스튜디오 (`/studio`, 관리자 비밀번호)

인스타그램 게시물을 계획하고 만드는 곳이에요.

- **콘텐츠 캘린더**: 날짜를 누르면 게시물이 생기고, 초안 / 준비 완료 / 게시함 상태로 관리해요.
- **카드 이미지**: 템플릿 6종(한 줄 훅·3대 이점·가격 비교·노선 소개·여행자 모집·이용 방법), 색 3가지, 피드 4:5·스토리 9:16. 글자를 고치면 바로 미리보기되고 PNG로 받아요.
- **캡션·해시태그**: 목적(구매자·가격·노선·여행자·안심)과 노선을 고르면 한국어/영어 템플릿 문구가 채워져요.
- **추적 링크**: 게시물마다 `?src=ig_<이름>` 링크가 생기고, 그 링크로 온 방문·클릭·등록 수를 보여 줘요. `/admin`의 유입 경로 표에도 같이 잡혀요.
- **✨ AI로 만들기**: 아이디어를 적으면 AI가 카드 세트·캡션·해시태그를 만들어요. 사진을 올리면 사진 내용을 보고 문구를 쓰고, "사진 + 문구" 카드의 배경으로 써요.
- **참고 게시물 보관함**: 마음에 드는 게시물 캡처를 올리면 AI가 스타일(표지 방식·배치·말투·색)을 읽어 두고, AI로 만들 때 골라서 참고해요.
- AI 기능은 Railway 변수 `OPENAI_API_KEY`가 필요해요(모델은 `OPENAI_TEXT_MODEL`, 기본 `gpt-5.6-terra`). `AI_MOCK=1`이면 키 없이 가짜 결과로 흐름만 확인해요.
- 게시물은 `DATA_DIR/posts.json`, 참고 게시물은 `DATA_DIR/refs.json`, 사진은 `DATA_DIR/assets/`에 저장돼요.

## 구매 요청 · 결제 화면 (미리보기 `/requests`)

Grabr 견적 화면처럼 3단계로 나눴어요: ① 물건(링크·가격·수량·포장·크기) → ② 배송(경로, 📍 현재 위치로 받을 도시 찾기, 기다릴 기간과 날짜) → ③ 주문 요약.

- 보상금: 물품 가격의 10%, 최소 $10 (`lib/fees.ts`의 `FEES`에서 바꿔요)
- 구매자는 물품 가격 · 수고비(보상금, 기본보다 올릴 수 있음) · (예상 세금) · 결제 수수료(2.9% + $0.30)만 내요. 구매자 플랫폼 수수료는 없고, TripCarry 몫은 수고비의 20%로 여행자 정산에서 떼요.
- 주류·담배는 요청 단계에서 차단해요 (카테고리와 품목 이름 둘 다).
- 비교 가격: "DHL·FedEx 정식 국제 배송 시 예상가"를 크기별 특송비 대략값으로 계산해 얼마 아끼는지 보여 줘요. 더 비싸지 않으면 솔직하게 직구가 더 쌀 수 있다고 안내해요.
- 묶음 제안: 싼 물건은 2~3개를 함께 부탁하면 개당 비용이 얼마나 줄어드는지 보여 줘요.
- 현재 위치: 버튼을 누를 때만 위치를 묻고, 좌표를 약 1km 단위로 줄여 OpenStreetMap(Nominatim)에서 도시 이름만 찾아요. 저장하지 않아요.

## 운영 규칙 (운영자 개입 없이 자동 처리)

규칙 값은 `lib/rules.ts` 한 곳에서 바꿔요. 랜딩·`/rules`·약관·미리보기에 같이 반영돼요.

- 자동 취소·환불·정산: 희망일 24시간 전 미매칭 → 자동 취소 / 결제 후 48시간 내 구매 인증 없음 → 자동 취소·전액 환불·여행자 7일 정지 / 전달 후 24시간 미확인 → 자동 수령·정산
- 사진 증빙 3단계: ① 물품+영수증 ② 포장 상태 ③ 수령 코드 입력(즉시 완료) 또는 수령 사진
- 평점 4.0 이하(후기 5개 이상) 매칭 제한, 면세 초과 시 예상 세금 동의 필수, 금지 품목(의약품 포함) 자동 차단
- `/help` 자주 묻는 질문 10개 자동 안내, `/rules` 구매 전 확인, 미리보기 거래 화면의 1:1 채팅
- 미리보기(`/orders`)에서 "24시간 빨리 감기"로 자동 규칙을 확인할 수 있어요.

## 수요 조사

첫 노선은 **도쿄 → 서울**, 품목은 **온라인으로 안 파는 매장 한정품**, 공급자는 **도쿄에 살거나 자주 오가는 사람**이에요.

- 언어는 한국어 · English · 日本語. 처음 방문하면 브라우저 언어로 정하고, 오른쪽 위에서 바꿀 수 있어요.
  일본어 방문자는 반대 방향(서울 → 도쿄) 구매자로 보고, 2단계 수요를 미리 재는 용도로 써요.
  약관·규칙·도움말은 일본어가 없어서 영어로 보여 줘요.
- 모든 버튼은 **사전 등록 팝업**을 열어요. 이메일만 필수예요.
  - 구매자: 방향, 원하는 물건, 건당 보상금
  - 공급자: 거주 형태, 1년 왕복 횟수, 짐 여유, 건당 최소 보상금
- 한정품 카드의 **"이거 원해요"**는 품목별로 누른 사람 수를 세요. 품목은 `lib/drops.ts`에 있고,
  매장 정가·리셀 시세를 확인하면 `retail`·`resale`(원)을 채우면 카드에 가격 비교가 나와요.
- 방문·버튼 클릭·등록을 서버에 기록해요. 링크에 `?src=이름`을 붙이면 유입 경로별로 따로 세요.
  예: `https://사이트주소/?src=ig_bio`
- 결과는 `/admin`(비밀번호 필요)에서 봐요.
  - 내가 넣은 테스트 등록은 표의 **테스트** 버튼으로 통계에서 빼요 (기록은 지우지 않아요).
    `ADMIN_TEST_EMAILS`(쉼표 구분) 변수로도 지정할 수 있어요.
  - **투자자용 (이메일 가리기)** 버튼을 누르면 이메일이 `ab***@naver.com`처럼 가려져요.
  - CSV에는 공급자 답변과 테스트 여부(`test` 열)도 들어가요.
- 기록은 `DATA_DIR` 폴더의 `events.jsonl`, `signups.jsonl`, `test-emails.json`에 쌓여요.
- 레딧 게시판 후보와 게시글 초안: [`docs/reddit-plan.md`](docs/reddit-plan.md)

## Railway 배포

1. Railway → **New Project → Deploy from GitHub repo** → 이 저장소 선택
2. 서비스 **Variables**에 추가
   - `ADMIN_PASSWORD` — 결과 화면(`/admin`) 비밀번호
   - `DATA_DIR` = `/data`
3. 서비스를 우클릭(또는 ⌘K) → **Attach Volume** → Mount path `/data`
   (Volume이 없으면 재배포할 때마다 모은 이메일이 사라져요. Volume을 붙이면 Railway가 `RAILWAY_VOLUME_MOUNT_PATH`를 넣어 주고,
   앱은 `DATA_DIR`이 Volume 밖을 가리켜도 Volume 안에 저장해요.)
   `/api/health`에서 `"storage":"persistent"`, `/admin` 위쪽에서 "저장 공간 연결됨 ✓"이면 제대로 붙은 거예요.
4. **Settings → Networking → Generate Domain**으로 주소를 만들어요.
